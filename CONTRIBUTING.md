# Contributing / Cómo contribuir

Thanks for considering a contribution. Keep changes focused, avoid adding analytics or remote image upload, and document any new dependency with its license.

## Development
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Run `npm test` and `npm run build` before submitting a pull request.

## Privacy rule
Image processing must remain client-side unless a future change is clearly optional, documented, and approved. Never silently upload user images.

## Español
Gracias por contribuir. Mantén los cambios enfocados, no añadas analítica ni carga remota de imágenes, y documenta la licencia de cualquier dependencia nueva.

Antes de enviar cambios, ejecuta `npm test` y `npm run build`. El procesamiento de imágenes debe seguir siendo local, salvo que una función futura sea opcional, esté documentada y se apruebe explícitamente.
